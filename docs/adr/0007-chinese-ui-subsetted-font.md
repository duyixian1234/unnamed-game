# Chinese UI with a subsetted CJK font

All in-game text is Chinese, while Bevy's embedded default font (FiraMono subset) covers ASCII only — every non-ASCII glyph rendered as tofu (the two em dashes in the HUD hint line and shop rows were the visible cases). We decided to translate the whole UI to Chinese rather than keep English and patch the dashes, because the player/developer audience is Chinese-speaking and upcoming HUD copy (weapon names, hints) is easier to author in Chinese. Game data strings (shop item names, weapon names) are translated directly in `game-core` — names are game data, and a display-side English→Chinese mapping layer was judged pure overhead for a single-person repo.

To respect the 25 MiB per-file deployment budget (ADR 0006) we do **not** ship a full CJK font: `tools/gen_font.sh` downloads Noto Sans SC, subsets it with `pyftsubset` against the exact glyph set used by the UI (scanned from all rendered strings, plus digits/punctuation), and commits the result as a static asset `assets/fonts/ui.ttf` (ADR 0002: assets are generated offline by `tools/` scripts, never fetched at runtime). The accepted cost is discipline: any new Chinese string requires re-running `gen_font.sh` before it renders, judged worth it because the alternative — a multi-MB font — measurably slows first load for a handful of glyphs.
